# PetCare - WebApp

Aplicación web para la administración y seguimiento de mascotas.

## Descripción

PetCare es una aplicación web que permite a los usuarios administrar la información de sus mascotas desde una plataforma centralizada. Su objetivo es facilitar el registro y seguimiento de datos importantes relacionados con el cuidado de las mascotas.

Este repositorio contiene el desarrollo de la aplicación web, encargada de presentar las interfaces al usuario, gestionar la autenticación y comunicarse con el servicio API del proyecto.

## Tecnologías

- **Python:** lenguaje de programación.
- **Flask:** framework para el desarrollo de la aplicación web.
- **HTML5 y CSS3:** estructura y presentación de las interfaces.
- **JavaScript:** funcionalidades e interactividad.
- **Bootstrap 5:** diseño de interfaces responsivas.
- **PostgreSQL:** almacenamiento de usuarios y perfiles.
- **Requests:** comunicación con el servicio API.
